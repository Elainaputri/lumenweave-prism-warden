Lumenweave: Prism Warden is a tactical optical-refraction arena game — pilot the Aether Loom, bend photonic beams through refraction prisms, and defend the Chrono-Astrolabe Core across five Astral Cycles against the Eclipse Leviathan.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — everything runs from local files.
